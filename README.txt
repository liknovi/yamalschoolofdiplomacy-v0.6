# Ямальская школа дипломатии — визуальная версия 7

## Состав
- `index.html` — структура и тексты
- `style.css` — дизайн, адаптивная сетка и анимации
- `script.js` — заставка, таймер, появление блоков, деликатный параллакс и мобильное меню
- `assets/` — три оригинальных логотипа из предоставленного архива
- `CNAME` — custom domain `yamalschoolofdiplomacy.ru`

## Как проверить
Откройте `index.html` в браузере. Для корректной загрузки шрифта нужен интернет. Перед заменой опубликованной версии проверьте все разделы на телефоне и компьютере.

## Публикация
Сделайте резервную копию текущих файлов репозитория, затем замените `index.html`, `style.css`, `script.js`, `CNAME` и папку `assets` файлами из архива. Настройки GitHub Pages и DNS менять не нужно.
